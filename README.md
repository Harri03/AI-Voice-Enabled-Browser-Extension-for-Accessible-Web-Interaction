# AI-Voice-Enabled-Browser-Extension-for-Accessible-Web-Interaction
AI Voice-Enabled Browser Extension allows users to control web browsers using voice commands. It converts speech to text, uses NLP to detect user intent, and executes actions like opening websites, searching, and navigating pages. This improves accessibility and enables hands-free, efficient web interaction.
Features
Voice command recognition
Hands-free browser control
Open websites using voice
Navigate pages
Accessible interaction
